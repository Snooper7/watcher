# Project Roadmap

> Telegram-бот для автоматического мониторинга цен на Wildberries и Ozon с отчётами в группу и ручным поиском по запросу.

## Milestones

- [x] **Инфраструктура и фундамент бота** — Python-проект, SQLAlchemy-модели (User, Product, PriceRecord, Favorite), логирование, `/start`, `/help`
- [x] **Скрапер Wildberries** — headless-скрапер (Playwright + stealth), поиск по бренду+фильтрам, URL-фильтрация, изображения товара
- [x] **Ручная проверка цен (`/check`)** — пошаговый диалог: бренд → фильтры → результат с ценой и фото
- [x] **Система избранного** — сохранение запросов в БД, `/favorites` с inline-кнопками, повторный запуск запроса
- [x] **Скрапер Ozon** — headless-скрапер для Ozon с тем же интерфейсом `BaseScraper`, поиск по бренду+фильтрам
- [x] **Управление списком товаров (`/add`, `/remove`, `/list`)** — добавление/удаление конкретных товаров по ссылке или названию для периодического мониторинга
- [ ] **Планировщик и автоматический сбор цен** — cron-задача в 7:00, 13:00, 20:00: обход всех отслеживаемых товаров, запись минимальных цен в PriceRecord
- [ ] **Групповые отчёты** — отправка отчёта с минимальными ценами (WB + Ozon) в указанную Telegram-группу по расписанию
- [ ] **Деплой и мониторинг** — VPS (Ubuntu), systemd-сервис с автозапуском, ротация логов, уведомления об ошибках
